# Nova Disk

## 定义

[[Nova]] 中面向磁盘驻留、大规模、多租户场景的混合索引变体：fast layer（质心导航）+ base layer（向量存储），底层为 [[Inverted File Index|IVF]] 聚类组织。

## 核心要点

1. **为什么选 IVF 而非磁盘图索引**：IVF 的簇局部组织带来**有界的单查询 I/O 与基本顺序的访问**，并天然适配按租户内存预算**按需簇加载**；磁盘图索引（如 [[DiskANN]]）则面临重建代价、内存 PQ/热点节点驻留、合并期写放大与随机 I/O 驱动的 P99 长尾。
2. **两层结构**：fast layer 紧凑存放 $C$ 个簇质心，可选叠加图索引（质心列表后紧跟邻接表 $N(v_i)$）；base layer 存放向量。
3. **共享 base file 布局**：避开「一簇一文件」导致的大量小文件；所有向量存于共享 base file，每簇最多 $N_{max}/C$ 个槽位，簇耗尽配额时 `expand` 为该簇单独创建新 base file，其余簇槽位逻辑分配但不物理写入。向量与 `ctid` 分区域连续存放以改善顺序访问与 cache 局部性。
4. **[[Adaptive Scan|自适应扫描]]**：根据查询与候选质心的距离分布动态校准遍历范围——距离彼此相差在 **20%** 内则穷尽扫描邻近簇，某质心占绝对主导则提前终止。
5. **无锁插入**：解析目标簇后按当前大小 $S_i$ 算出确切槽位写入，并原子自增 $S_i$。
6. **vacuum 双指针重定位**：目标槽先标不可见 → 复制源条目并可见 → 源槽失效；瞬时重复由 `scan` 去重保证正确性。
7. **量化与效率**：使用 [[RaBitQ]] 量化，索引构建时间仅占整体的 12%–14%，存储显著压缩。

## 代表工作

- [[Nova]]: 作为磁盘/大规模场景的索引变体；GIST-1M 上 95–96% recall 时达 5000+ QPS、P99 8.2ms。
