# Azure Database for PostgreSQL
## 定义
Microsoft Azure 的托管 PostgreSQL 服务。
## 核心要点
1. 被 [[Aurora Limitless Database]] 归为「传统云数据库，聚焦**单实例内的垂直伸缩**」一类。
2. 与 Limitless 的差异是缺少内建的透明水平分片（该能力在 Azure 侧由 [[Citus]] 承担）。
## 代表工作
- Azure Database for PostgreSQL（Azure 产品）。
