# OpenViking

## 定义

字节跳动开源的面向 AI Agent 的 Context Database，开源了 [[VikingMem]] 核心能力的一个子集，用于社区研究与技术知识共享。

## 核心要点

1. 定位为"自我演化的上下文数据库"（Self-evolving Context Database for AI Agents）。
2. 是 VikingMem 商业系统之外，面向开源社区的能力子集发布，便于学术界复现与扩展 Memory Base 相关研究。
3. 地址：https://github.com/volcengine/OpenViking

## 代表工作

- [[VikingMem]]: 其核心能力子集通过 OpenViking 开源。
