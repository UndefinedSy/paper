# Keyword Graph

## 定义

一种以关键词为节点、与关联记忆片段相连的辅助索引结构，用于在标准混合检索（dense + sparse）语义相似度过低时提供补充召回路径。每个关键词的 embedding 由包含该关键词的所有记忆片段 embedding 平均而来。

## 核心要点

1. **动机**：默认混合检索对诸如"你还记得我的昵称吗？"这类查询效果不佳——直接查询与间接记忆之间语义相似度很低。
2. **构建方式**：关键词 embedding = 其所在记忆片段 embedding 的平均，以更好捕捉语义特征；关键词节点与关联记忆相连。
3. **检索方式**：作为辅助路径，与主混合检索路径分别排序、分配不同配额（主路径更大）后再合并，而非直接合并原始结果（实证发现直接合并效果更差）。
4. **代价**：是消融实验中延迟开销最大的模块（+25.8ms p95），但贡献效果提升约 1.91 分（LOCOMO, GPT-4o-mini）。

## 代表工作

- [[VikingMem]]: 作为 Memory Retrieve 模块中混合检索的辅助召回路径。
