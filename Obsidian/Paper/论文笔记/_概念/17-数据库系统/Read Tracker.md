# Read Tracker

## 定义
Read Tracker（RT）是 [[MVTO]] 类协议中的冲突检测结构：为每个键记录**曾经读过它的最大事务时间戳**，用于判断一个写是否破坏了既有的读顺序。

## 核心要点
1. **语义**：$RT(x) = \max\{ts(T_i) \mid T_i \text{ 读过 } x\}$。若某写事务 $T_j$ 满足 $ts(T_j) < RT(x)$，说明它在语义上早于某个已读事务却要改数据，违反读序 → 该写被中止。
2. **不持久化**：RT 功能类似读锁，但只存在于内存中。这一点直接决定 [[K2Plus]] 的故障恢复策略——失效节点上的 RT 无法恢复，**在途事务一律视为已中止**，不尝试恢复，否则会削弱一致性保证。
3. **索引方式**：[[K2Plus]] 用 B+ 树索引 RT 以实现快速查找与更新。
4. 与 [[Write Stream]] 配对使用：RT 管读序，WS 管未提交可见性。

## 代表工作
- [[K2Plus]]：每个数据节点维护 RT/WS，作为并发控制元数据；节点故障时不恢复 RT，从而放弃恢复在途事务。
