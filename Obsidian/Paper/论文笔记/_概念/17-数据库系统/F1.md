# F1
## 定义
Google 构建在 [[Spanner]] 之上的分布式 SQL 数据库，服务 AdWords 等关键业务。
## 核心要点
1. 证明了大规模分布式 SQL 处理的可行性；[[Aurora Limitless Database]] 称自己的贡献在于**最小化跨分片通信**。
2. 另一项被 Limitless 反复引用的贡献是**在线异步 schema 变更**（[[Schema Versioning]]），被列为 PostgreSQL 应当学习的方向。
3. F1: A distributed SQL database that scales (VLDB 2013)；Online, asynchronous schema change in F1 (VLDB 2013)。
## 代表工作
- F1: A distributed SQL database that scales (VLDB 2013)。
