# Azure Cosmos DB
## 定义
Microsoft Azure 的全球分布式多模型 NoSQL 数据库服务，提供五档可调一致性级别。
## 核心要点
1. 多模型支持（文档、键值、图、列族）与多 region 分发。
2. 被 [[Aurora Limitless Database]] 归为「提供多模型支持但**常以一致性换可用性**」一类。
## 代表工作
- Azure Cosmos DB（Azure 产品）。
