# Iterative Query

## 定义

不预先固定候选集放大倍率，而是从小批次开始、按需增量扩张搜索前沿，直到满足结果数或过滤条件的检索机制。

## 核心要点

1. **动机**：后过滤（Type 3）计划中静态的 [[Recall Amplification Factor|放大因子]] $\sigma$ 无法适应运行时数据分布，容易在过滤强时拿不满 $k$ 个结果。
2. **做法**：借助图索引（[[HNSW]]）的**增量遍历特性**，先生成一个小候选批次；若标量过滤后结果少于 $k$，则通过探索相邻节点逐步扩张搜索前沿，直到满足要求或触发停止条件。
3. **定位**：是 Type 3 后过滤流水线的**精化**，而非新的计划类型；与 Type 4 的回调式预过滤相互独立。
4. **代价模型**：需额外计入每轮迭代代价与满足 $k$ 所需的预期迭代次数。
5. **思想来源**：受 [[VBASE]] 等工作的启发。

## 代表工作

- [[Nova]]: 在 [[Nova Memory|NovaM]] 上实现，用于缓解静态放大因子导致的 recall/延迟失配。
