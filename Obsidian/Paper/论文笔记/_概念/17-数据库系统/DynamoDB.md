# DynamoDB

## 定义

Amazon 的非关系型云数据库服务，提供可扩展性和可预测性能，是 Dynamo 和 SimpleDB 的经验结晶，与 Cloud Bigtable 最为类似。

## 核心要点

1. Amazon 的托管式 NoSQL 云服务
2. 脱胎于 Dynamo（key-value store，增量可扩展）和 SimpleDB（表模型，但规模/性能受限）
3. DynamoDB 论文同样是长期运行经验总结（~10年）
4. 提供可预测的性能和完全托管的运维
5. 与 [[Bigtable]] 的 Cloud Bigtable 最为类似，均为非关系型云数据库服务
