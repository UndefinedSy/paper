# Load Balancing

## 定义
Load Balancing 是把计算或存储负载在可用资源之间重新分配的过程，目标是消除热点、提升整体资源利用率与吞吐。

## 核心要点
1. **[[K2Plus]] 的两条实现路径**：
   - **区域内资源弹性**（默认）：靠存储解耦，节点过载时把 [[Physical Partition|物理分区]]拆分并迁移到欠载节点；实测拆分+迁移 3 s 内完成，聚合吞吐提升 **5.7×**，均衡后各节点 CPU 超 80%；
   - **全局键重分区**（非常规手段）：K2+ 正常运行时**不依赖**全局键重分区做均衡，因此不引入跨区域协调。
2. **细粒度是优势**：因为一个 CPU 核可承载多个物理分区，K2+ 可只迁移热点分片的**部分**分区，把负载摊平到各核，而非整 shard 搬家。
3. **区域自治红利**：不同区域可为同一 global range 维护**独立的物理分区布局**，故副本区域**无需镜像**主区域的拆分或迁移——负载均衡完全不涉及跨区域通信。
4. **前置动作**：先做**故障前探测**（pre-failure detection）识别不健康节点并施加流控保住 goodput；热点不消退才触发真正的拆分与迁移。

## 代表工作
- [[K2Plus]]：App#2 中负载均衡贡献了 1.42× 加速（291.55 → 415.05 Ktps）。
