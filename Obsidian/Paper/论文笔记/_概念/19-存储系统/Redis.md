# Redis

## 定义

广泛使用的开源内存数据结构存储，支持字符串、哈希、列表、集合等丰富数据类型，单线程事件循环模型处理命令，可选持久化（RDB/AOF）但核心工作集驻留内存。

## 核心要点

1. 单线程命令处理模型使其在吞吐测试中与多线程系统的线程数对比"结构上不公平"——这正是 [[SOS]] 论文选择排除 Redis 作为性能对比基线的原因，而只用 [[RocksDB]] 做受控对比。
2. 内存驻留带来亚毫秒级延迟，但每 TB 成本显著高于 SSD 方案（约 10×–30×），是 PB 级场景下成本不可行的核心原因。
3. 从 Redis 迁移到 SSD 驻留的 KV 存储（如 SOS）是常见的降本路径，在保持可接受延迟的前提下大幅降低 TCO。

## 代表工作

- Redis（Sanfilippo, 2009）。
- [[SOS]]：相关工作与生产经验部分提及 Redis 作为内存存储基线及迁移降本案例（内部计费数据显示平均 TCO 降低 84%）。
