# Cloud Block Storage

## 定义

云块存储（CBS，如 AWS EBS、Azure Ultra Disk、阿里云 [[ESSD]]）是以块设备形式提供的持久化云存储，典型特征是带宽随所购容量强耦合扩展，且必须挂载在网络带宽足够的 VM 上才能发挥性能。

## 核心要点

1. **带宽–容量耦合**：高吞吐往往要求预留远超实际需求的容量，使"高带宽档位"的每 GB/s 成本接近甚至超过内存。
2. **VM 网络带宽绑定**：CBS 无法独立使用，须挂载在网络带宽匹配的 VM 上，高带宽存储部署常被迫选用高规格、高成本 VM。
3. 不同云厂商的 CBS 产品普遍存在类似的带宽–容量–成本关系，不是单一厂商特例。

## 代表工作

- [[PolarKV]]：实证分析 CBS 的带宽-容量-成本耦合特性，据此确立"存储是容量资源、内存是带宽资源"的分层设计准则。
